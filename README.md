# NOVA AI

Luxury AI chat application powered by NVIDIA NIM APIs.

## Features

- AI chat
- Multiple NVIDIA API keys
- Automatic key rotation
- Model fallback
- Vision/image understanding
- Image generation
- Responsive UI
- Render deployment

## Environment Variables

Set these on Render:

NVIDIA_API_KEY_1
NVIDIA_API_KEY_2
NVIDIA_API_KEY_3
NVIDIA_API_KEY_4
NVIDIA_API_KEY_5
NVIDIA_API_KEY_6

Never commit real API keys to GitHub.

## Local Run

Install:

pip install -r requirements.txt

Set environment variables.

Run:

python app.py

Open:

http://localhost:10000
